Sent mail is monitored for promises, approvals, deliverables and unanswered requests. Replies in the same chain are tracked so you can see what still needs follow-up.
Automatic new-task discovery focuses on the last 30 days. Multi-recipient messages are treated as important, while later messages in an existing task chain are attached to that task and can raise it to URGENT.
Google Chat spaces and direct messages are scanned for action items. New messages that materially continue an existing Chat task are attached to that task and make it URGENT.
